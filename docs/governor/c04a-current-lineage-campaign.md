# C04a aggregate-completeness current-lineage campaign

## Status

This is inert campaign preparation, not a C04a module or release candidate. It cannot register a
module, change configuration, delivery, storage, or deployment. C04a remains source NO-GO.

The tracker defines C04a precisely: the current finish gate collapses current evidence to a set of
criterion ids. That incorrectly accepts multiple records for one required criterion and known
optional/unrequired evidence. The required repair is one opt-in immutable required-observation
cohort in a host plan plus a sorted exact criterion-to-evidence mapping bound into the completion
certificate. It must reuse existing action/effect/evidence identities and task-version CAS, adding
no table, column, or index.

## Deterministic source gate

The paired test validates exactly 100 unique prompts and ids, twenty cases for each class, the
fixed three-criterion cohort, two accepting classes, and explicit rejection categories for duplicate
required evidence, extra known optional evidence, and stale/inadmissible evidence. This verifies
only campaign data, not current source or installed C04a behavior.
