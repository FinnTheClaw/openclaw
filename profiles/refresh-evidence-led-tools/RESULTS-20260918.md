# Source continuation experiments — in progress, not promoted

## Narrow observed defect

The guidance comparison exposed a completed exec(find) followed by a reasoning-only model response. The existing recovery selection treated the earlier exec as potentially effectful and switched to a tools-disabled finalizer, even though its result was persisted and the requested status edit was still undone. The final answer was truthful but incomplete.

This is a continuation-selection problem, not permission to replay earlier actions. It does not match upstream #140367's missing-finish_reason EOF signature.

## Decision

Candidate62 remains experimental/not promoted: the broader comparison tied overall and had a no-op case-level regression. It demonstrates useful post-write continuation but does not yet meet the preset promotion criterion. Default gateway/TUI remains unchanged.

The next narrow observed-failure correction is existing settled-turn finalization for the exact predispatch malformed-call rejection after settled work, treating only the failed terminal's partial text as incomplete. Latest upstream #142176 also retains visibility/replay vetoes and does not repair this variant. No generic parser relaxation or new retry family is planned.

Do not activate a candidate merely because its build or source tests pass. Successful runs without exposure of an error branch do not prove that branch fixed.
